## 🚀 О скрипте `finally_5.sh`

Данный скрипт представляет собой интерактивную утилиту для управления правами доступа (`chmod`) и интеграции исполняемых файлов в систему.

### ✨ Основной функционал:
* **Умный поиск файлов:** Если файл не найден по точному совпадению, скрипт ищет похожие объекты без учёта регистра.
* **Безопасное изменение прав:** Автоматически выставляет права `755` для файлов или рекурсивно для директорий.
* **Интеграция в PATH:** Позволяет в один клик сделать созданный симлинк доступным из любой точки системы.
* **Поддержка разных Shell:** Поддерживает автонастройку для **Fish** (`fish_add_path`), **Bash** и **Zsh**.
